# Quantum Terminal — Screenshot Capture Checklist & Instructions

## Overview
This document provides step-by-step instructions for capturing high-resolution, presentation-grade screenshots of **Quantum Terminal** for sales decks, marketing materials, and technical due-diligence documentation.

---

## 1. Environment & Screen Setup Guidelines

### Required Viewport Configurations
- **Desktop Screenshots**: `1920 × 1080` resolution at 100% browser zoom level.
- **Mobile Screenshots**: `390 × 844` resolution (Apple iPhone 12/13/14 Pro standard viewport).

### Pre-Capture Quality Audit Checklist
- [x] **No Secret Exposure**: Ensure no real API keys, secrets, passwords, or tokens are displayed.
- [x] **No Local File Paths**: Ensure developer console and local filesystem directory strings are hidden.
- [x] **Clean UI Elements**: Ensure no overlapping modals, duplicate buttons, or broken panels are visible.
- [x] **Realistic Data**: Ensure active trading assets display realistic pricing (`BTCUSDT` ~ $65,000, `EURUSD` ~ 1.0850).
- [x] **Demo Badge Visible**: Ensure header `● DEMO MODE` gold badge is clearly visible.

---

## 2. Step-by-Step Screenshot Capture Checklist

### Desktop Screenshots (`1920 × 1080`)
- [ ] **01 — Main Presentation Dashboard**: Open app; capture landing dashboard modal showing 12 module cards.
- [ ] **02 — Professional Multi-Chart Workstation**: Set 2x2 grid layout; enable EMA and VWAP indicators.
- [ ] **03 — Canvas Paper Order Dragging**: Place paper order; show active SL/TP drag handles on chart canvas.
- [ ] **04 — Portfolio Analytics & Risk Lab**: Open Bottom Panel -> Positions & Risk Desk tabs; capture account metrics.
- [ ] **05 — Market Replay Studio**: Open Replay Studio tab; show playback speed controls and tick playback log.
- [ ] **06 — Options Analytics & Greeks**: Open Options Desk panel; show call/put chain, Greeks table, and payoff graph.
- [ ] **07 — Script Studio Engine**: Open Script Studio window (`ScriptEditor.tsx`); show strategy expression code.
- [ ] **08 — Level-2 DOM Depth & Footprint**: Open DOM tab; show bid/ask volume depth and time-and-sales feed.
- [ ] **09 — Market Data Gateway**: Open Market Data tab; show WebSocket status (`CONNECTED`) and tick feed.
- [ ] **10 — Smart Order Router (SOR)**: Open SOR tab; show multi-venue order splitting simulation table.
- [ ] **11 — System Health Panel**: Click **⚡ Health** in header; capture diagnostic readiness status modal.

### Mobile Screenshots (`390 × 844`)
- [ ] **12 — Quantum Mobile Pro Touch Layout**: Toggle mobile layout mode; show touch chart canvas, economic event overlays (`CPI`, `FOMC`), vertical price scale dragging, and sticky bottom navigation.
